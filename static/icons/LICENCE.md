# Icons

The sprite is inlined at `templates/jinja2/_partials/icons.html` rather than served from
here, because an external `<use href="...#id">` only resolves when the sprite is
same-origin and the static host is not settled yet. Line icons come from Lucide, the four
brand marks from Simple Icons. To add one, copy its paths from lucide.dev into a new
`<symbol>` with the same attributes as its neighbours.
